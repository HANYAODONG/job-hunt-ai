# 第四阶段分工：围绕组长前端完成真实功能对接

## 1. 阶段目标

组长提交的新前端后续作为最终展示前端使用。本阶段不再按抽象算法模块分散推进，而是围绕前端页面逐个打通功能：

```text
页面能打开
  -> 按钮能点击
  -> 前端能请求后端
  -> 后端能返回数据
  -> 页面能展示结果
  -> 没有后端数据出口的地方写清楚缺口
```

当前重点页面：

```text
/fusion-demo      融合排序演示页
/search           岗位搜索页
/recommendations  推荐页
/diagnosis        人岗诊断页
/learning         学习路径页
/graph            全景图谱/动态图谱页
/signals          岗位市场雷达页
/recruitment      企业端岗位管理页
/candidates       企业端候选人匹配页
```
