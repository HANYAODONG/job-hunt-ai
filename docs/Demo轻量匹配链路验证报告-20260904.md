## 5. 本轮发现并修复的问题

1. 修复Compose中轻量匹配服务错误查找`/artifacts`的问题，统一通过`JOB_HUNT_REPO_ROOT=/app`读取岗位池和候选人数据。
2. 将完整后端上传接口的`query`改为可空，支持网页只上传简历直接推荐，避免100%返回422。
3. 为独立轻量入口补充`runtime_pipeline_mode`和`parser_mode`，保证前端及测试可以确认实际链路。
4. 恢复增强简历解析结果的顶层`email`字段，保持旧接口契约兼容。
5. 为离线评测脚本补充输出目录自动创建。
6. 新增真实HTTP批量评测脚本和前端浏览器冒烟脚本。
7. 新增后端`.dockerignore`，避免上传副本进入Docker构建上下文。
8. 移除前端重复的全局代理配置，并补齐合法Web App Manifest，消除浏览器控制台错误。

```powershell

docker compose up -d --build
```

运行整站100份HTTP上传评测：

```powershell
$p = (Get-Location).Path
docker run --rm -v "${p}:/workspace" -w /workspace jobmatch-ai-backend:local `
  python scripts/evaluate_real_upload_api.py --base-url http://host.docker.internal:18080
```

```powershell

```
