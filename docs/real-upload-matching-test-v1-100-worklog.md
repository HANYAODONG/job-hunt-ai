## 算法组/本机后续执行要求

测试必须逐份调用前端真实上传接口，并从请求开始计时，直到最终推荐结果返回。每份至少记录：

```text
sample_id
upload_start/upload_end
parse_ms
matching_ms
total_ms
predicted_role_id
top1_job_id/top2_job_id/top3_job_id
gold_role_id
accepted_jd_ids
role_hit
jd_hit_at_1/jd_hit_at_2/jd_hit_at_3
error
```

汇总时：

```text
总耗时 = 100 份 total_ms 之和
平均人岗匹配时长 = 总耗时 / 成功处理的样本数
```

平均时长必须包含 PDF 解析时间，不能只统计排序接口时间。
