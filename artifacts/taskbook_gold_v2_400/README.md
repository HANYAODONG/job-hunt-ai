# 400条任务书人工审核包

本目录包含以下固定样本：

- 400条JD
- 400份简历
- 400组人岗匹配

三个`*_annotation_adjudicated.csv`最初由Codex机器辅助预标，随后经项目小组逐条人工审核并确认无误，现已冻结为人工复核金标。完整批准记录和前后文件哈希见`human_review_approval_manifest.json`。

## 正式人工金标结果

- JD技能解析Micro-F1：94.45%
- 简历技能提取Micro-F1：94.73%
- 简历经验年限完全一致率：100.00%
- 人岗匹配5折折外Accuracy：100.00%
- 人岗匹配5折折外F1：100.00%
- 匹配等级：0级13条、1级105条、2级244条、3级38条

正式评估文件为`artifacts/taskbook_acceptance_20260830/human_gold_metrics_400.json`，其中`formal_acceptance_eligible=true`。JD解析、简历提取和人岗匹配均超过任务书90%的指标要求。升级后的匹配模型采用“BGE语义+技能/经验+岗位族本体门控”，在5折折外预测中Accuracy和F1均为100%。旧模型去掉岗位族门控时Accuracy为70.50%，说明该门控是本轮主要增益来源。

当前结果证明模型在这400条冻结同域金标上满足验收口径。由于金标最初使用同一岗位族体系辅助预标，最终报告应同时披露该来源，并补充一批从未参与规则设计的外部盲测样本，用于验证跨数据源泛化能力。

## 审核记录

本次采用“小组审核机器辅助预标”的方式，不是双人独立盲标。每条裁决记录保留原始预标来源，并统一写入`team_human_review_approved`审核标记。A/B空白表继续保留，后续如需更严格的论文级一致性实验，可再次进行双人盲标并计算一致率。

金标等级口径为：`0=无关`、`1=相邻但缺口较大`、`2=可推荐`、`3=强匹配`。

重新运行正式评估：

```powershell
py scripts/evaluate_taskbook_gold.py `
  --gold-dir artifacts/taskbook_gold_v2_400 `
  --output artifacts/taskbook_acceptance_20260830/human_gold_metrics_400.json
```

## 样本说明

JD按企业、政府、历史来源近似等比例抽样。现有历史匹配来源只有72条正样本和528条负样本，因此原始抽样来源无法组成200正、200负；400条审核集保留全部72条来源正样本并固定抽取328条来源负样本。Codex先按统一岗位族规则给出0至3级建议，项目小组随后完成了人工复核确认。
